## 4. Modifications made to the copied material

Every change below was made **to the copy**, never to the original folders.

| File(s) | Change | Why |
|---------|--------|-----|
| `experiment-2/15-paper-redesign/python/paper_XX_improved.py` (×15) | Added `_visualizations_dir()`: `EX2_VIS_DIR` env var → folder next to the script → `cwd/visualizations`, created on demand | Original hard-coded a relative `../visualizations` path that failed when the script was run from another working directory |
| `experiment-2/15-paper-redesign/python/run_all_visualizations.py` | Resolves its own folder, `chdir`s there, runs the 15 scripts in sorted order | Same portability problem; the runner now works from any working directory |
| `experiment-1/Iris_Visualization_Colab.ipynb`, `iris_visualization_colab.py` | Added `find_iris_csv()` (env var `IRIS_CSV` → local files → `/kaggle/input/**` → Colab upload) and `OUT_DIR`/`save_figure()` (`/kaggle/working/outputs`, `/content/outputs`, `./outputs`) | The notebook previously required a manual upload and silently assumed one folder layout; it must run unattended on Kaggle and Colab |
| `experiment-3/src/data_loader.py` | Added `set_outputs_dirname()` / `outputs_dir()` and routed `ensure_output_dirs()` through them | `run_eda.py --output <folder>` was parsed but ignored — every artefact was written to a hard-coded `outputs/` folder |
| `experiment-3/src/run_eda.py` | All 14 `root / "outputs"` occurrences now call `outputs_dir(root)`; `main()` passes `output_root` to `run_all()` | Same defect — the documented `--output` flag did nothing |
| `experiment-3/src/visualization.py` | `save_figure()` uses `outputs_dir(root)` | Same defect, figure path |
| `experiment-3/.gitignore` | *(kept)* keeps ignoring the regenerated ZIP | ZIP is regenerable and duplicates tracked files |
| `experiment-3/` notebooks | Re-executed after the `--output` fix | Recorded outputs must correspond to the committed code |

**Not regenerated:** the 15 `paper_XX_poor.png` baselines in experiment 2 have no
generator script in the original material. They are shipped as authored evidence
of the "before" state and are never silently replaced.
