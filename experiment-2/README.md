# Experiment 2 — Research-Paper Visualization Redesign (EXERCISE-2)

Fifteen published research figures, each diagnosed for readability problems and
rebuilt as a clear, honest Python/Matplotlib visualization — plus the three
visualizations that belong to the exercise itself.

**Kaggle (private):** https://www.kaggle.com/code/arulmariaagnes/experiment-2-research-visualization-redesign

## Aim

Take figures that were published in real research papers, identify what makes
them hard to read (dense flows, misaligned segments, overplotted polylines,
edge crossings, small-multiple overload …), and produce a redesigned version
that communicates the same structure with less cognitive load.

```bash

python python/research_visualization_redesigns.py
```

Figures go to `visualizations/` next to the script, to `./visualizations` when
run inside a notebook, or to whatever folder `EX2_VIS_DIR` points at:

```bash

```

Rebuilding the notebook after editing any script:

```bash
python build_kaggle_notebook.py
```

## Design principles applied

1. **Reduce non-data ink** — no decorative frames or redundant gridlines.
2. **Direct labelling** — values sit next to their marks instead of in a distant legend.
3. **One clear reading order** — grouping and spacing direct the eye.
4. **Restrained, consistent colour** — colour encodes meaning, not decoration.
5. **Titles that state the takeaway** — the title answers "what should I notice?".

## Academic-integrity note

Original research figures are identified by paper and figure number. Where exact
numerical values were not available in the accessible text or tables, the
redesign is an **educational/conceptual reconstruction** and does not claim to
reproduce the authors' empirical results. The improved figures are original
Python-generated designs; no publisher figure is redistributed.

The 15 `paper_XX_poor.png` baselines ship with the package as authored evidence
of the "before" state — no script in this repository regenerates them, and the
notebook says so explicitly instead of pretending to.
